The full set lives in the **catalog app**: search by name or meaning, filter by category or color
count, customize colors, size, speed and trigger, and copy the install command or the JSX for any icon.

<Cards>
  <Card title="Open the catalog" href="/icons" />
</Cards>

Every icon is drawn in the [sharp house style](https://github.com/kovenlabs/animated-icons/blob/main/packages/animated-icons/STYLE.md):
square caps, mitered corners, no rounded shapes. Each has 1–3 color slots and 2–3 variants of its own.
